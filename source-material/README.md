# Source Material

This directory contains Abdo's approved development reference material. It is tracked because the private development team needs the original Excel templates and report samples to build and validate the application.

## Contents

- `workbooks/`: eleven original Excel workbooks from October and November 2026, plus a weekly sales comparison workbook (`مقارنه يوميه المغرب (3) (1).xlsx`).
- `images/2026-11-07/`: Foodics Orders Summary, Product Mix report photographs, and a manual transcription summary.

## Handling rules

- Keep this repository private.
- Read these files; do not overwrite them.
- Do not edit the historical source files to make them fit the application.
- Do not move this material to a public repository, paste it into public issues, or include employee biometric data here.
- Create anonymized fixtures in `sample-data/` for automated tests.
