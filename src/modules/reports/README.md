# Reports

- `field-map.ts` reads the reviewed Phase 1 field map (`docs/phase1/field-map.json`).
- `contracts.ts` lists which fields each Phase 2 prototype shows and the contract examples.
- `trace.ts` attaches a field ID and saved-record reference to every displayed value.

Excel export of the five report families (Phase 9) is in `src/modules/exports`; see docs/phase9/EXCEL_REPORTS.md.
