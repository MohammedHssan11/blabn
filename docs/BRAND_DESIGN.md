# B.Laban interface references

The branch workspace uses cobalt blue for actions and navigation, deep blue for headings, white for work surfaces, and pale sky blue for supporting areas. The internal layouts prioritize staff tasks, with a dessert photograph on account screens and a simpler, compact workspace after sign-in.

- [B.Laban website](https://blaban.net/) for the brand's own product photography and presentation.
- [Official B.Laban channel](https://www.youtube.com/@BlabanOfficial) for its public campaign imagery.
- [B.Laban mark registration](https://ised-isde.canada.ca/cipo/trademark-search/2388730) for the documented blue, sky blue, and white palette. The app uses a simple typographic initial.

The sign-in photo is an original image generated with the built-in image tool and compressed for the web. The asset is `public/brand/dessert-studio.webp`.
